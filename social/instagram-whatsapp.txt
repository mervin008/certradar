=== WHATSAPP — MESSAGE TO FRIENDS (personal, send 1:1 or to a group) ===

Got into the early access for *Jev*, a new AI model that launched last week.

It's not a chatbot. You genuinely can't talk to it — it cannot produce a sentence.
What it does instead: you give it a situation plus a list of questions, and it
answers each one with a probability. Which option. How bad. Yes or no, and how
sure.

So I spent the week finding out what that's actually good for, using my own work
as the test. (Quick context: every padlock next to a website address is a
certificate, they all expire, and I look after a few thousand of them.)

The thing I built reads a complaint like *"we renewed it but it's still broken"*,
works out which certificate out of 500 is the actual problem, and asks a question
when it can't tell. A third of a second each. The whole test run cost me about a
tenth of a cent.

Then I rebuilt the exact same thing on a normal ChatGPT-style model to compare.
Same accuracy — but 10x the cost, twice as slow, and here's the bit I keep
telling people: it answered *"100% certain"* to every single question, including
one where it was plainly wrong. Jev gave that same question 29%.

That difference is the entire reason this kind of model exists.

https://certradar-jev.mervinjones.dev


=== WHATSAPP — MESSAGE FOR WORK / TECH GROUPS ===

Got early access to Jev, TypeSafe's System One model from last week's launch.
Not an LLM — no text generation. You send state plus typed questions (choice,
score, yes/no) and get typed answers with calibrated probabilities back.

Built certificate incident triage with it to see where it fits. The split that
worked: code does expiry, chain building, SAN matching and CAA, plus finding
which of 500 certs a ticket is about. The model only reads the ticket and weighs
findings for the certs code already matched. Never sees the inventory — 12
candidates max, so cost doesn't scale with the estate.

Best moment: a ticket with no hostname mapped to a service with 81 certificates,
so it asked the reporter for the CN instead of guessing. The answer led to a pod
still serving a cert that expired 3 hours earlier while the renewed one sat
undeployed.

Also rebuilt the same pipeline on gemini-3.5-flash-lite as a control. Same
accuracy, 10x cost, 2.4x latency — and every evidence answer came back 1.00,
including an obviously unrelated one. Jev said 0.29 to that. Calibration is the
whole product.
